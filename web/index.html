Análisis estático de pickles, PyTorch, safetensors, GGUF y plantillas de chat, en tu navegador. Los archivos se leen por partes en tu equipo y nunca se suben. Sin promesas de «100 % seguro».

01 / Archivos en tu equipo

Detecta pickles con código (también dentro de .pt, .bin, .npz o con otro nombre), estructuras safetensors/GGUF inconsistentes, inyección en plantillas Jinja y auto_map. El análisis AST de archivos Python solo está en la CLI.

02 / Repositorio público

Tu navegador consulta directamente a Hugging Face. Solo metadatos públicos fijados a un commit, nunca pesos.

    04 / Terminal y agentes (MCP)

    Misma lógica, sin dependencias (Python 3.10+):

    pip install git+https://github.com/wncu/modelguard
modelguard scan ./modelo --format text
modelguard verify ./modelo owner/model --partial
claude mcp add modelguard -- modelguard mcp

    El servidor MCP expone herramientas de solo lectura (modelguard_scan, modelguard_hub, modelguard_verify) para Claude Code, Claude Desktop o tu IDE.
