# Security policy

Do not execute or deserialize unknown model code to use this scanner. The current scanner is heuristic and does not certify files or model behavior. Treat reports as untrusted text, not signed attestations.

For scanner vulnerabilities, use GitHub private vulnerability reporting once enabled by the maintainer. If unavailable, request a private contact without posting exploit details or personal data publicly. Do not label an upstream author malicious based on an extension or one unusual output. Reports must include artifact revision, reproducible evidence and limitations.
